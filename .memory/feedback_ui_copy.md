2026-11-11 用户看了本地界面后指出：很多文案"一点都不面向用户，就好像把我的 prompt 在产品里转述了一遍"。点名的例子有：

- 「八拍是自动猜的；播到正确的"1"时点一下」
- 「不是你传的，改动会发给上传者确认。」
- 「用一句话描述画面就行……输入的是人名、标签或者活动名时会先把它们列出来」
- 「认识的话点进去起个名字；同一个人被分成了两份……」

当天已经全面改过一遍，前端文案和后端报错都改了。

**Why:** LockCloud 是交付给队员用的产品，界面要像 Apple 一样高级、简练、有质感。

**How to apply:**
- 只说用户要知道的结果和动作，不解释怎么实现的。不出现转码、向量、抽帧、FC、cluster、后台慢慢跑这类词。
- 不用口语和语气词：不写「了、一下、试试、东西、没法、TA、好了」。
- 统一说法：
  - 编辑（不说修改），发送申请，他人上传的，永久删除。
  - 浅色、深色、自动。
  - 已 + 动词（已保存、已恢复）。
  - 「出现 N 次」。
- 空状态写一个短标题，最多再加一句。按钮二到四个字。
- 后端报错会直接弹给用户看，同样要写成用户语言，异常原文只进日志。改了报错文字要同步改 tests 里钉住的那句。
